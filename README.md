# Игра "Змейка" на Java

## Описание
Классическая игра "Змейка" с графическим интерфейсом на JavaFX. Проект поддерживает два режима игры: интерактивный (управление игроком) и неинтерактивный (автоматическая игра).
При запуске программы появляется окно. Чтобы начать игру, надо нажать на любую кнопку на клавиатуре.
Игра началась - змейкой управляем с помощью стрелок на клавиатуре.
Если надо поставить на паузу - клавиша P (англ.раскладка).
Если за 5 минут игра не закончилась, она останавливается автоматически.
